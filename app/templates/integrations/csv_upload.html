Device Protocol

The integration device POSTs to POST {{ url_for('integrations.csv_upload_submit', _external=False) }} over application/x-www-form-urlencoded. No authentication is required.

  • Shape 1 key=<MAC> + data=<csv-body>. The CSV body is URL-encoded by the device; rows are newline-separated.
  • Shape 2 Multipart — file field csv_file, optional form field key.
  • Shape 3 Raw Content-Type: text/csv body, optional X-Key / X-Filename headers.
Example device call 
POST {{ url_for('integrations.csv_upload_submit', _external=False) }}
Content-Type: application/x-www-form-urlencoded

key=9C-95-6E-53-28-17&data=ts%2Ctimestamp%2Cm_schneider_...%0A1783087604%2C0%2C...

Returns 200 with {status:"ok", upload_id, row_count, detail_url}.

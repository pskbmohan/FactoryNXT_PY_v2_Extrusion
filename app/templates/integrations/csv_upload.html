CSV Import

Upload a CSV file to integrate external data into the system.

Upload CSV File

First row should contain column headers. UTF-8 encoded files only.

How It Works

  1. 1 Choose a .csv file from your machine.
  2. 2 The first row is treated as column headers.
  3. 3 Uploaded contents are displayed on a separate preview screen.
  4. 4 Preview up to 500 rows per upload.

Server-to-Server / API Usage

Another server can POST a CSV directly to this endpoint — no authentication required. Endpoint: POST {{ url_for('integrations.csv_upload_submit', _external=False) }}

  • Option A Multipart form — field name csv_file. Returns JSON when Accept: application/json is sent.
  • Option B Raw CSV body — set Content-Type: text/csv. Optional header X-Filename: orders.csv to name the file.
Example curl commands 
# Multipart upload, JSON response
curl -X POST {{ url_for('integrations.csv_upload_submit', _external=False) }} \
  -H "Accept: application/json" \
  -F "csv_file=@orders.csv"

# Raw CSV body push from another server
curl -X POST {{ url_for('integrations.csv_upload_submit', _external=False) }} \
  -H "Content-Type: text/csv" \
  -H "X-Filename: orders.csv" \
  --data-binary @orders.csv

Successful POST returns 200 with {status, filename, row_count, columns, headers, preview_url}.

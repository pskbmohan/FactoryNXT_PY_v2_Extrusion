What is this?

The BOM is the recipe for each finished profile. It defines the part number, the alloy required, the unit weight per metre, and all the process steps it must go through. When you create a Work Order, the system looks up the BOM to know exactly what materials to reserve and what routing to follow.

How to use it

  1. Go to BOM → All BOMs from the sidebar.
  2. Search by part number or description to find a specific BOM.
  3. Click a BOM to view full details: alloy, weight, dimensions, and routing steps.
  4. To edit, click "Edit BOM" — you can change the description, update the routing, or mark it inactive.
  5. To create a new BOM, click "New BOM" — enter part number, alloy, weight, and link the routing.
  6. Approve the BOM — until approved, it cannot be used in Work Orders.

Key fields explained

FieldWhat it means
Part NumberUnique ID for this finished profile (e.g. PROF-6063-FH-40X20).
DescriptionHuman-readable name — shape, size, alloy.
AlloyThe aluminium grade required — 6063-T5, 6061-T6, etc.
Unit WeightWeight per metre in kg — used to calculate billet consumption.
Standard LengthTypical extrusion length (e.g. 6,000 mm) — the stretcher cuts to this.
Routing StepsThe sequence of manufacturing steps — pulled from the Routing Builder.
StatusDraft (being created), Approved (ready for WOs), or Inactive (obsolete).

💡 Tips

  • Always get BOM approval before creating Work Orders — unapproved BOMs can't be used.
  • If you change the routing, update the BOM — WOs use the BOM's routing, not the standalone routing.
  • Use consistent part numbering — include alloy and key dimensions in the part number for clarity.

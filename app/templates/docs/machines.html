What is this?

Machines is the master register of every piece of equipment in the plant — extrusion presses, saws, furnaces, stretchers, coating lines. Each machine has a type, home station, current status (Running / Idle / Under Maintenance), and an is_active flag. The OEE and Operations modules both read from here.

📸 The Machine Register — every piece of equipment with type, location, status, and maintenance history.

How to use it

  1. Go to Machines from the sidebar — all machines appear in a table.
  2. Click a Machine ID to view details — capacity, home station, maintenance history, OEE trends.
  3. To add a new machine, click "New Machine" — enter ID, name, type, home station, and capacity.
  4. Monitor status changes — Running (producing), Idle (available), Under Maintenance, or Decommissioned.
  5. Set is_active to False when a machine is retired — it won't appear in scheduling or Operations.

Key fields explained

FieldWhat it means
Machine IDUnique code (e.g. MCH-PRESS-01). Permanent identifier.
NameHuman-readable name — Press #1, Aging Oven FRN-AGE-01, etc.
TypeWhat kind of machine — Extrusion Press, Saw, Furnace, Coating Line, Stretcher.
Home StationWhich station this machine belongs to — links to Stations module.
CapacityMachine's rated capacity — tons for presses, kg for furnaces, pcs/day for coating lines.
StatusRunning (active WO), Idle (waiting), Under Maintenance, or Decommissioned.
Last PMDate of last preventive maintenance — used to schedule the next one.
ActiveYes/No — inactive machines don't appear in scheduling or Operations.

💡 Tips

  • Keep machine IDs consistent across the factory — operators, planners, and maintenance all use them.
  • Review machine status weekly — machines marked "Idle" for long periods may need redeployment or retirement.
  • Link the machine register to Maintenance — every machine should have a maintenance schedule.

What is this?

Traceability answers the question: "Where did this profile come from and where did it go?" For any finished piece, you can trace back to the exact billet lot, the alloy composition, the die used, the press that ran it, the oven cycle it went through, and the operator on shift. If a customer reports a defect months later, you can pull the complete history in seconds.

How to use it

  1. Go to Traceability from the sidebar.
  2. Enter a Profile Lot number, WO number, or shipment ID in the search box.
  3. The system builds the traceability tree — showing upstream (billet lot, die, press, operator) and downstream (aging, finishing, shipment).
  4. Click any node to drill into that record — WO details, die history, operator log, etc.
  5. Export the traceability report as PDF for customer audits or quality investigations.

Key fields explained

FieldWhat it means
Profile LotThe finished lot ID — assigned during production or finishing.
WO NumberThe work order that produced this lot.
Billet LotThe raw material lot consumed — links to the mill test certificate and composition.
Die UsedWhich die was in the press — includes run count and nitriding history.
Press & OperatorWhich machine and who was operating — for shift accountability.
Aging CycleFurnace, program, temperature, and duration — critical for temper verification.
ShipmentWhich shipment this lot went in — customer name and dispatch date.

💡 Tips

  • Keep traceability reports for at least 5 years — customers may request them long after delivery.
  • If a defect is reported, trace both ways — find other lots from the same billet lot that may have the same issue.
  • Use the "Export PDF" button for customer quality reports — it includes the full tree in a professional format.

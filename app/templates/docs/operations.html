What is this?

Operations is the real-time shop floor control panel. Operators use this screen to start and stop jobs, log production counts, report downtime, and hand off work between stations. It's the heartbeat of the factory — every piece of aluminium that moves through the plant is tracked here.

How to use it

  1. Operator selects their Station on login — the screen loads the current WO automatically.
  2. Current active WO appears with part number, target, and progress so far.
  3. Tap "Start Production" to begin the shift timer and mark the job as running.
  4. Every hour (or per batch) tap "Log Output" and enter the piece count. This updates the progress bar and inventory.
  5. If the machine stops, tap "Report Downtime" — select a reason code from the list (die change, maintenance, material shortage, etc.).
  6. When all pieces are extruded, tap "Complete Step" to move the job to the next process (e.g. Aging or Stretching).

Key fields explained

FieldWhat it means
Produced / TargetLive piece count vs the WO quantity. Updates when you log output.
Current StepWhich process step this station is running (Extrusion, Aging, Coating, etc.)
DieThe die currently loaded in the press. Links to Die Management.
Billet LotThe raw material lot being consumed. Links to Traceability.
Operator / ShiftWho is running this station right now and on which shift.

💡 Tips

  • Log output frequently — hourly is better than end-of-shift for accurate OEE.
  • Always use a reason code for downtime — it feeds the OEE analysis later.
  • "Complete Step" automatically moves the WO to the next station defined in the routing.

What is this?

Tool Shop manages all the maintenance, repair, and reconditioning work done on dies and other tooling. When a die comes back from the press worn or cracked, a Tool Shop Job is raised. Technicians log their work — measurements, repairs performed, test results — and the die is cleared back to Available when done.

📸 The Tool Shop jobs board — track every die repair from intake to clearance.

How to use it

  1. Go to Tool Shop → All Jobs to see the full list of repair and maintenance work.
  2. When a die arrives, click "New Job" — enter the die code, describe the issue, and set priority.
  3. Assign a technician from the dropdown — they'll see the job on their queue.
  4. Technician logs work — measurements taken, repairs done, parts replaced, time spent.
  5. When repair is complete, the technician marks "Awaiting Test" — QA verifies the die before clearance.
  6. Once test passes, click "Clear Die" — the die returns to Available status in Die Management.

Est. CompletionTarget date for the repair to be finished.

💡 Tips

  • Track turnaround time — dies stuck in "Waiting" status are blocking production.
  • For recurring issues on the same die, check if it's time to retire rather than keep repairing.
  • Use the "Scrapped" status only when the die is beyond repair — it removes it from the active inventory.

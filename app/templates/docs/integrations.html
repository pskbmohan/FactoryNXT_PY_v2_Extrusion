What is this?

Integrations connect FactoryNXT to external systems — ERP platforms (SAP, Tally), customer order portals, WhatsApp notification gateways, and barcode/RFID scanners. The API page also documents all REST endpoints for developers who want to build custom integrations.

📸 Integration connectors — status, last sync, and configure buttons for each external system.

How to use it

  1. Go to Integrations → Available Connectors from the sidebar.
  2. Click Configure on the integration you want to set up.
  3. Enter API keys or webhook URLs — these come from the external system (SAP, Twilio, etc.)
  4. Click Test Connection — green ✅ means it's working; red ❌ means check your credentials.
  5. Enable the integration to start syncing — data will flow automatically.
  6. Monitor the sync status — "Last sync" shows when data was last exchanged.

Key fields explained

FieldWhat it means
Connector NameWhat the integration does — WhatsApp Alerts, ERP Sync, Barcode Scanner.
ProviderThe platform or service — Twilio, SAP, Zebra, etc.
StatusConnected (working), Active (syncing), Needs Config (setup not complete), or Error (check credentials).
Last SyncWhen data was last exchanged — "2 mins ago" means it's working.
API Key / WebhookCredentials for the external system — keep these secret.

💡 Tips

  • Test connections before enabling — a broken integration can cause data sync failures.
  • Monitor "Last sync" — if it's stale (hours old), there may be a connection issue.
  • For custom integrations, use the REST API — all core entities (WOs, dies, inventory) have endpoints.

Welcome to FactoryNXT MES Documentation

Everything you need to run your aluminium extrusion factory — from work orders to shipment, all in one place.

🚀 Quick Start in 5 Steps

  1. Create a Work Order — Go to Work Orders → New → enter Part Number, Quantity, and Due Date, then click Release.
  2. Schedule it on a Press — Open Planning and drag the WO onto a machine × day cell. Or let APS auto-schedule it.
  3. Start Production — The operator opens Operations, selects their station, and taps "Start Production".
  4. Track Progress Live — Watch WOs move through Process Line in real time as each step completes.
  5. Ship to Customer — Pack and dispatch from Logistics. Weights are checked automatically against BOM targets.

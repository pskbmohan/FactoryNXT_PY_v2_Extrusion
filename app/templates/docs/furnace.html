Furnace & Heat Treatment

Manage aging ovens and heat treatment cycles — ensure every profile reaches the right temper.

What is this?

After extrusion, aluminium profiles must be heat treated (aged) to reach their target temper — for example T5 or T6. This module manages every furnace in the plant: what's currently loaded, which heat treatment program is running, temperature profiles, and automatic alerts if temperature deviates.

How to use it

  1. Go to Furnace → Load Batch from the sidebar.
  2. Scan or select the WO lots to load into the furnace. The system checks capacity.
  3. Select the Heat Treatment Program — e.g. T5-6063-STD or T6-6061-HIGH.
  4. Click "Start Cycle" — start time is logged automatically and the temperature profile begins.
  5. The system alerts you if temperature drifts outside ±5°C of the target — act immediately.
  6. When the cycle completes, click "Unload" — all loaded WOs move to the next process step automatically.

Key fields explained

FieldWhat it means
Furnace NameUnique ID for each aging oven (e.g. FRN-AGE-01).
StatusRunning, Heating (not yet at temp), Idle (empty), or Alarm (temp deviation).
Current TempLive temperature reading from the furnace thermocouple.
Target TempThe program's target temperature (e.g. 175°C for T5).
ProgramThe heat treatment recipe — time, temperature ramp, and hold duration.
Loaded WOsWhich work orders are currently in this furnace.
Time RemainingHow long until the cycle completes and the furnace can be unloaded.
AlarmShows if temperature is outside ±5°C — red = over temp, yellow = under temp.

💡 Tips

  • Never ignore an over-temp alarm — it can ruin the temper and make the entire batch scrap.
  • Load furnaces efficiently — partial loads waste energy and time.
  • Use the "Time Remaining" display to plan the next load — start unloading just before the cycle ends.

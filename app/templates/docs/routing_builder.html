What is this?

Before a Work Order can run, the system needs to know the exact sequence of manufacturing steps for that part — this is called the Routing. The Routing Builder lets you define exactly which stations, machines, and operations each part number must go through, and in what order. Think of it as the manufacturing recipe.

📸 The Routing Builder shows each step with station, time estimate, and hold points for QA.

How to use it

  1. Go to Routing Builder → New Routing from the sidebar.
  2. Enter the Part Number this routing applies to. Only one routing per part is active at a time.
  3. Add each step: select Station, Machine Type, and operation type.
  4. Set estimated cycle time for each step — this is used by APS for scheduling.
  5. Mark "Hold Points" — steps where QA sign-off is required before the next step can begin.
  6. Save and Approve — the routing is now available for WOs of this part number.

Key fields explained

FieldWhat it means
Part NumberThe finished profile this routing is built for.
Step OrderSequence number — steps run in order from 1 onward.
StationWhere the work happens (saw, press, furnace, etc.)
Estimated TimeHow long this step typically takes — used for scheduling.
Hold PointIf yes, the WO cannot advance to the next step until QA approves.
QA Sign-offA final inspection step where quality must approve before shipping.

💡 Tips

  • Copy an existing routing and modify it — much faster than building from scratch for similar profiles.
  • Keep hold points to a minimum — each one adds delay. Use them only for critical quality gates.
  • If a step is outsourced, you can still add it — mark it as "External" and the system will track it.

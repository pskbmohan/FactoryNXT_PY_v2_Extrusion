What is this?

Coating (powder coating or anodizing) runs on a shared line that serves multiple WOs per day. The Coating Schedule plans which WOs go through which colour and process in which order, optimising for colour sequence (light to dark, to minimise cleaning time between runs) and line capacity.

📸 The Coating Schedule — plan time slots by colour sequence to minimise line cleaning.

How to use it

  1. Go to Coating Schedule → Today's Plan from the sidebar.
  2. Unscheduled coating WOs appear in the right panel — drag them into time slots.
  3. Observe the colour sequence rule — light colours first (white, silver), then dark (bronze, black).
  4. The system shows cleaning time between colour changes — factor this into the schedule.
  5. Confirm the plan — operators see it on the coating line screen.
  6. Mark each slot Done when the run completes — the WO moves to the next step automatically.

OperatorWho is running the coating line for this slot.
StatusScheduled (planned), Running (in progress), or Done (complete).

💡 Tips

  • Always schedule light-to-dark — it saves 20–30 minutes of cleaning between runs.
  • If you must go dark-to-light, add an extra cleaning slot (the system suggests this automatically).
  • Leave 30-minute gaps between runs for line cleaning and colour changeover.

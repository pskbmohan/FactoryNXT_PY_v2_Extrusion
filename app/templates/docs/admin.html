What is this?

Admin is where the system administrator manages users, roles, and plant settings. You create user accounts, assign them roles (Admin / Planner / Operator / Quality), and control which modules each role can access. You also set up plants, shift patterns, and global defaults here.

How to use it

  1. Go to Admin → Users from the sidebar (only accessible to Admin role).
  2. To add a new user, click "New User" — enter username, full name, email, and initial password.
  3. Assign a role — Admin, Planner, Operator, Quality, or Viewer.
  4. Set status to Active — inactive users cannot log in.
  5. To edit a user, click "Edit" — change role, email, or reset password.
  6. To deactivate a user (e.g. someone who left the company), click "Deactivate" — they can't log in but their history is preserved.

Plant Settings

In addition to users, Admin also controls:

  • Plant Master Data: plant name, address, default timezone, working hours.
  • Shift Patterns: define shift A (06:00–14:00), shift B (14:00–22:00), shift C (22:00–06:00).
  • Global Defaults: OEE availability threshold (e.g. 80%), nitriding alert threshold (e.g. 80% of die limit), weight tolerance (±2%).
  • Notification Channels: email SMTP settings, WhatsApp API key.

💡 Tips

  • Use the principle of least privilege — give users only the access they need for their job.
  • Deactivate users immediately when they leave — don't just change the password.
  • Review inactive users quarterly — remove accounts that haven't been used in 6+ months.
  • Keep only 1–2 Admin accounts — too many admins increases risk of accidental changes.

What is this?

Containers (trays, racks, baskets) carry profiles between stations. Container Management tracks where every container is right now, what it contains, and whether it's available for loading. This prevents the common problem of "lost trays" and ensures the aging oven team always has empty containers ready.

How to use it

  1. Go to Containers → All Containers from the sidebar.
  2. Filter by type (Aging Tray, Coating Basket, etc.) or status (Empty, In Use, In Furnace).
  3. Click a Container ID to see its full history — which WOs it carried, how many cycles, current location.
  4. To assign a container, click "Assign to WO" — scan the container barcode or select from the list.
  5. When empty, mark it "Empty Available" so other teams know it's ready to use.
  6. If a container is missing, flag it as "Lost" so the system stops expecting it.

Key fields explained

FieldWhat it means
Container IDUnique ID printed/etched on the container (e.g. CTR-001).
TypeWhat it's used for — Aging Tray, Stretching Rack, Coating Basket, Packaging Tray.
StatusEmpty Available (ready), In Use (has material), In Furnace (aging), Ready to Ship (packed for dispatch), or Lost.
Current LocationWhere the container physically is right now.
ContentsWhich WO and piece count — blank if empty.
Last MovedWhen the container was last transferred between stations.

💡 Tips

  • Always scan containers when moving them — this keeps the location data accurate.
  • If you can't find a container, check the "In Use" filter — it might be at a different station than expected.
  • Mark containers as "Lost" if they go missing for more than 48 hours — prevents false availability.

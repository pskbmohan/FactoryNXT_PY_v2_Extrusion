Packaging

Define how each profile is bundled and packed for shipping to the customer.

🏠 Home › Logistics › Packaging

What is this?

Packaging defines how finished profiles are to be bundled, boxed, or crated for each part number. It records the packing method, units per pack, theoretical pack weight, and any special instructions (e.g. foam interleaving, corner protection). The packaging record travels with each lot to the dispatch bay.

📸 Packaging configuration — how to bundle, weight per pack, and customer-specific packing instructions.

How to use it

  1. Go to Packaging → All Configs from the sidebar.
  2. Select a part number to view or edit its packaging configuration.
  3. Set the packing method — Bundle Wrap, Box, Crate, or Customer-Specific.
  4. Enter units per pack and calculate the theoretical pack weight.
  5. Add special instructions — foam interleaving, corner protectors, labelling requirements, etc.
  6. Save the config — it's now available for all shipments of this part number.

Key fields explained

FieldWhat it means
Packing MethodHow the profiles are packed — Bundle Wrap, Box, Crate, or Custom.
Units Per PackHow many pieces go in one bundle/box/pallet.
Theoretical Pack WeightCalculated weight per pack — used for shipment weight verification.
StrappingHow the bundle is secured — steel bands, plastic wrap, etc.
Special InstructionsCustomer-specific requirements — foam interleaving, corner guards, labelling.

💡 Tips

  • Different customers often have different packaging requirements — always check the customer spec before packing.
  • Keep theoretical pack weights accurate — they feed into the shipment weight verification.
  • Photo-document special packing (foam, corner protectors) so the team knows exactly what "good" looks like.

What is this?

A Station is a physical area of the factory (e.g. Extrusion Bay, Aging Area, Coating Line). Stations group machines together and define the workflow zones. They also control what operations are available at each location and which users can access them.

How to use it

  1. Go to Stations from the sidebar — all defined stations appear in a table.
  2. Click a Station to view its details — machines, operations allowed, and user access.
  3. To add a new station, click "New Station" — enter code, name, type, and assign machines.
  4. Define operations available at this station — this controls what operators see on their screen.
  5. Set access roles — only users with these roles can work at this station.
  6. Save — the station is now available in the Routing Builder and Operations module.

Key fields explained

FieldWhat it means
Station CodeUnique ID (e.g. STN-EXTRUSION). Used in routings.
NameHuman-readable name — Extrusion Bay, Aging Area, etc.
TypeProduction, Quality, Logistics, or Support — categorises the station.
MachinesWhich machines are physically located at this station.
Operations AvailableWhat work can be done here — controls the operator's screen options.
Access RolesWhich user roles can work at this station (Operator, Quality, Supervisor, etc.)
StatusActive (available for scheduling) or Inactive (decommissioned).

💡 Tips

  • Set up stations to match your factory's physical layout — it makes routing definition intuitive.
  • Restrict access carefully — only Quality roles should be able to close NCRs at the inspection station.
  • If you reorganise the factory, update station-machine assignments — it affects how WOs are scheduled.

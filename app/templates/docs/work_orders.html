What is this?

A Work Order (WO) is the instruction to manufacture a specific product in a specific quantity. Every extrusion run starts here. Think of it as the factory's to-do list — each item has a part number, quantity, target dates, and tracks its progress from DRAFT right through to COMPLETED.

How to use it

  1. Navigate to Work Orders from the sidebar — you'll see the full list of current and past orders.
  2. Click "New Work Order" — fill in Part Number, Quantity, and Due Date. The part must have an approved BOM.
  3. Click "Release" to make the WO visible to the shop floor. Draft WOs cannot be scheduled.
  4. The floor operator picks it up in Operations and clicks "Start".
  5. Progress updates automatically as each process step completes on the shop floor.
  6. Click "Complete" when all output is confirmed and final inspection is done.

Key fields explained

FieldWhat it means
WO NumberAuto-generated unique ID (e.g. WO-2026-001). Never edit this.
Part NumberThe finished profile being made — pulled from the BOM. Determines the routing.
QuantityNumber of pieces to produce. Once completed, actual output is compared against this.
Planned Start / EndTarget dates set by the planner. Used for scheduling and priority.
Priority1 (highest) to 5 (lowest). Affects APS scheduling when resources are tight.
StatusLifecycle: DRAFT → RELEASED → RUNNING → COMPLETED (or ON HOLD / CANCELLED).
NotesFree-text comments visible to operators. Use for special instructions.

💡 Tips

  • Always link a WO to a BOM part so the routing is auto-populated — don't enter steps manually.
  • You cannot Release a WO without an approved BOM — fix the BOM first.
  • Use ON HOLD sparingly — every held WO blocks capacity on the schedule.
  • Duplicate a completed WO to quickly create a repeat order for the same part.

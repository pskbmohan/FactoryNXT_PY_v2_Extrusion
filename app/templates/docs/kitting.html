What is this?

Kitting assembles all the materials and tooling needed for a Work Order before it starts production. Instead of operators searching for dies, billets, or containers mid-production, the kitting team prepares everything in advance. A kit is marked Ready when all components are confirmed present and correct.

How to use it

  1. Go to Kitting → Active Kits from the sidebar.
  2. Select a WO to kit — the system pulls the requirements from the BOM and routing.
  3. Gather components: billets, dies, containers, packaging materials — anything the WO needs.
  4. Check off each item as you collect it — the system updates the Available column.
  5. If an item is short (e.g. not enough containers), the system flags it in orange.
  6. When all items are ready, click "Mark Kit Ready" — the WO can now be released to production.

Key fields explained

FieldWhat it means
ComponentWhat's needed — billet alloy, die, containers, packaging, etc.
RequiredHow much is needed for this WO — calculated from BOM and quantity.
AvailableHow much is actually on hand — from inventory.
StatusReady (green, has enough), Short (orange, needs more), or Missing (red, not found).

💡 Tips

  • Kit WOs at least 24 hours before scheduled production — this gives time to find missing items.
  • If a component is consistently short, increase minimum stock levels in Inventory.
  • Never release a WO without a complete kit — mid-production shortages cause delays and quality issues.

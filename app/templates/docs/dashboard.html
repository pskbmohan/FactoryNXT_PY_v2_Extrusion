What is this?

The moment you log in, the Dashboard gives you a live snapshot of the entire factory. You can see how many work orders are running right now, whether machines are keeping up with targets, and whether any shipments are due today — all without opening a single sub-module.

📸 The Dashboard shows live KPIs, press utilisation, and recent factory activity.

How to use it

  1. Log in — the dashboard loads automatically on every login.
  2. Read the top KPI cards for an instant factory snapshot — active WOs, OEE %, open NCRs, and shipments due.
  3. Click any card to drill into that module and see more detail.
  4. Use the date picker (top-right) to change the reporting period — today, this week, or a custom range.
  5. Check the alerts bell icon — it shows unread KPI threshold breaches and notifications.

💡 Tips

  • Bookmark the dashboard and set it as your browser start page for a quick daily check-in.
  • KPI cards are clickable — treat them as shortcuts, not just static numbers.
  • Set up KPI Alerts so the system notifies you automatically instead of you checking manually.

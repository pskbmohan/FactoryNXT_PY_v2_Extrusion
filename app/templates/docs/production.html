What is this?

Production Tracking records every extrusion run in detail — how many pieces were made, actual billet weight consumed, scrap generated, and the press parameters used. This becomes the permanent production record for traceability and OEE calculations. If a customer ever asks "when was this made?", this is where you look.

How to use it

  1. Go to Production from the sidebar — the log shows all runs for the current day by default.
  2. Filter by date range, WO, machine, or operator to find specific runs.
  3. Click a Run ID to see full details: press parameters, billet lot chemistry, die used, cycle time.
  4. Export to CSV for reporting — management reviews, customer audits, or internal analysis.
  5. Compare good vs scrap to identify die or material issues (high scrap = investigate).

Key fields explained

FieldWhat it means
Run IDUnique ID for this production run. One WO can have multiple runs (e.g. across shifts).
Good PcsPieces that passed inspection and are available for the next process step.
Scrap PcsPieces that failed quality and cannot be reworked.
Billet LotThe raw material lot consumed — links directly to Traceability.
Die UsedWhich die was in the press — links to Die Management for press count tracking.
Start / EndRun duration. Used for OEE availability and performance calculations.

💡 Tips

  • Production records are permanent — they can't be deleted (only corrected with a note). This is by design for traceability.
  • Scrap above 2% usually indicates a die or material problem — check Die Management for wear patterns.
  • Use the Export button for monthly management reporting — it includes all fields shown here.

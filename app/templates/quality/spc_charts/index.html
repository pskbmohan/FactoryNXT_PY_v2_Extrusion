SPC Reference Guide
Process Capability Indices:
  • Cp: Potential capability - assumes centered process (USL - LSL) / 6σ
  • Cpk: Actual performance - accounts for centering, min(CPU, CPL)
  • Pp: Overall performance index using overall standard deviation
  • Ppk: Overall performance accounting for centering
Cpk Interpretation:
  • Cpk ≥ 1.33 - Excellent capability, minimal defects expected
  • 1.0 ≤ Cpk < 1.33 - Adequate capability with room for improvement
  • 0.67 ≤ Cpk < 1.0 - Marginal, defects may occur
  • Cpk < 0.67 - Poor capability, immediate improvement required

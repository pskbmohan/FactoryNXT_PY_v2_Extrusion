Backward Traceability Guide

Purpose: Given a work order, identify all raw materials (billets and dies) used in its production.

Use Cases:
  • Root Cause Analysis: Customer complaint → trace back to specific billet batch or die that caused the issue
  • Quality Investigation: Process deviation detected → identify which materials were being used at the time
  • Due Diligence: Verify material specifications for customer order fulfillment
How It Works:
  1. Enter work order ID or number to search
  2. All production records associated with that work order are retrieved
  3. Billet and die codes used in production are displayed
  4. "Forward Trace" links allow investigation of customer orders from specific batches
API Integration:
# Backward trace API call
GET /quality/traceability/api/backward/<wo_id>

Forward Traceability Guide

Purpose: Given a batch number (from raw material receipt or production), identify all customer orders that received product made from that batch.

Use Cases:
  • Customer Complaint Investigation: Customer reports quality issue → find which batches were used in their order
  • Recall Management: Raw material supplier issues recall → identify all customers who received product from affected batches
  • Quality Audit: Verify traceability chain completeness for customer orders
How It Works:
  1. Enter the batch number or heat number to search
  2. All production records associated with that batch are displayed
  3. If customer order line associations exist, those orders are listed below
  4. Use "Backward Trace" links to investigate raw materials for specific work orders
API Integration:
# Forward trace API call
GET /quality/traceability/api/forward/BATCH001

# Returns:
{
  "batch_number": "BATCH001",
  "trace_records_found": 5,
  "associated_customer_orders": [
    {"order_number": "CO2024-001", "line_id": "...", "quantity_ordered": "1000"}
  ]
}

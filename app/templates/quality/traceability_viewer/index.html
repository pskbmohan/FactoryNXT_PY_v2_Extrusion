Traceability System Reference
Data Flow:
  • Raw Material Receipt: Heat number assigned from foundry → stored in traceability system
  • Billet Production: Billet code generated, linked to heat number and batch
  • Extrusion: Die code used recorded, process parameters captured, work order associated
  • Quality Verification: SPC data, inspections, and tests linked to trace record
  • Customer Shipment: Customer order line association for forward traceability
Use Cases:
  • Search by Batch/Heat: Find all production associated with a raw material batch
  • Forward Trace: Given a batch number, find which customer orders received product from that batch
  • Backward Trace: Given a work order, identify the raw materials used in its production
  • Complaint Investigation: When a customer complaint arises, quickly trace back to root cause (material, die, process parameters)
API Integration:
# Search for traces
GET /quality/traceability/api/search?batch=BATCH001&heat=H12345

# Get detailed trace record
GET /quality/traceability/api/trace/<trace_id>

# Forward trace (find customer orders from batch)
GET /quality/traceability/api/forward/BATCH001

# Backward trace (find raw materials for work order)
GET /quality/traceability/api/backward/<wo_id>
